# v0.1.0 — Experimental source release

An offline companion for Scratch Arcade OS: a small WASM app, learned pet movement and a five-command Japanese voice classifier.

## Included

- Pet app source and PC simulator workflow.
- Learned movement policy and fixed log-mel voice model, with evaluation and reproduction tools.
- Source archive and SHA-256 checksum. Code is Apache-2.0; voice assets carry separate attribution/license terms.

## Known limits

- Latest handheld synthetic playback: **4/5 commands**, 0/5 negative activations, no internal errors. This is a ten-input device check, not general voice accuracy.
- The current model has no human-voice acceptance result. An earlier model scored 6/15 human commands.
- Pet can fail to launch after Wi-Fi use on the tested firmware. A normal restart recovers it. The compact-workspace OS fix is built but has not been installed or validated on the handheld.

Start with the [PC workflow](https://github.com/ayutaz/arcade-ai-pet/blob/v0.1.0/docs/pet-app.md). The simulator uses simulated voice results. Firmware/app binaries, recordings and upstream TTS weights are not distributed.
