## 仮説

新しいheadや数値形式を探す前に、学習用で覚えた範囲から外れた入力にも対応できる正則化を試す。[SpecAugmentの原論文](https://arxiv.org/abs/1904.08779)はfilter-bank特徴に時間/周波数方向のmaskなどを適用する方法を示している。ここでは発想を参考にmaskだけを使い、論文の大規模ASRの結果を本機の改善保証にはしない。

既存2,113特徴の最初の64time×32bandだけへ、学習時に連続区間のmaskを入れる。0はこの正規化済み特徴の平均値で、物理的な無音の意味ではない。energy64/duration1の末尾65値とラベル/元IDを変えない。時間最大6bin・周波数最大3bandを設計候補とするが、実装確認後までrecipeを固定しない。

## 次の契約

1. shape/軸/0埋め/境界/値域/入力不変と決定性を先行TDDで定義する。短い語の情報を消し過ぎるリスクも保持する。
2. 学習batchだけへ適用し、検証/校正/最終評価では必ず無効にする。既存maskなしを既定にし、独立したaugmentation RNGで元の学習順序用RNGを変えない。
3. 既存のCNN形状/数値23,411B/実行時の特徴処理を維持する。CPU小型fitとMPS確認、診断/選定の対応、step/期限を検証する。
4. 実source/容量の確認後に1構成だけを固定し、同じ元archive/保留/全24domainと結合条件/元neural回帰で比較する。新しいデータの生成/評価行の削除/再ラベルはしない。

改善しない場合もmask幅や強度だけの探索を続けず、記録した誤りと学習の汎化を再評価する。消費済み最終2組は使わず、実機a553/16app・実声6/15と既存不採用を維持する。新FWの個別許可は別工程。
